# 已平仓仓位收益展示修正

## 背景

持仓列表中，已平仓仓位的真实交易结果应以 `realizedPnl` 为准。旧逻辑会继续展示或叠加 `unrealizedPnl`，导致平仓后 CA 当前市值继续波动时，页面收益被放大或扭曲。

## 变更

- 已平仓仓位的列表展示收益只使用 `realizedPnl`。
- 已平仓仓位的未实现收益展示为 `0`。
- 后端持仓 API 对已平仓仓位返回前，会将 `unrealizedPnl` 和 `marketValue` 归零。
- 后端估值刷新只允许更新 `status = 'open'` 的仓位，避免已平仓仓位再次被刷新出未实现盈亏。

## 影响

- 已平仓行不再随 CA 当前市值变化而改变收益。
- 打开中的仓位仍按 `realizedPnl + unrealizedPnl` 展示实时浮动收益。
