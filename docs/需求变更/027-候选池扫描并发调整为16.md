# 候选池扫描并发调整为 16

## 变更内容

- 候选池 `watching` 项目的单轮扫描并发 worker 数量由 `6` 调整为 `16`。
- 当候选数量少于 `16` 时，worker 数量仍按实际候选数量收缩。
- 已买入项目仍使用独立的 `0.5s` 卖出检查循环，不受本次变更影响。
- 本次只调整 worker 数量，不修改 GMGN 的全局 `max_qps` 限速、买入规则或卖出规则。

## 预期影响

- 可以减少单个慢请求对整轮候选扫描的排队影响。
- 当 GMGN 全局 `max_qps=8` 成为主要瓶颈时，整轮扫描的理论下限仍受该限速约束，并发数提高不等于请求速率提高。
