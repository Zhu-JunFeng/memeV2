# 候选池扫描并发调整为 16

## 变更内容

- 候选池 `watching` 项目的单轮扫描并发 worker 数量由 `6` 调整为 `16`。
- 当候选数量少于 `16` 时，worker 数量仍按实际候选数量收缩。
- 已买入项目仍使用独立的 `0.5s` 卖出检查循环，不受本次变更影响。
- 本次只调整 worker 数量，不修改当时的 GMGN 限速、买入规则或卖出规则；后续已将限速调整为每个 Key 独立 `max_qps`，详见需求变更 028。

## 预期影响

- 可以减少单个慢请求对整轮候选扫描的排队影响。
- GMGN 后续改为每个 Key 独立 `max_qps=8`；两个可用 Key 时理论总吞吐约 `16 QPS`，16 worker 可以同时利用多个 Key 的额度。
