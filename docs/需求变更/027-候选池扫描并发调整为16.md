# 候选池扫描并发调整为 16

## 变更内容

- 候选池 `watching` 项目的单轮扫描并发 worker 数量由 `6` 调整为 `16`。
- 当候选数量少于 `16` 时，worker 数量仍按实际候选数量收缩。
- 已买入项目仍使用独立的 `0.5s` 卖出检查循环，不受本次变更影响。
- 本次只调整 worker 数量，不修改当时的 GMGN 限速、买入规则或卖出规则；GMGN 当前采用整体 `10 QPS`，详见需求变更 029。

## 预期影响

- 可以减少单个慢请求对整轮候选扫描的排队影响。
- GMGN 当前整体限制为 `10 QPS`；16 worker 用于减少慢请求排队，但不会突破全局请求速率。
