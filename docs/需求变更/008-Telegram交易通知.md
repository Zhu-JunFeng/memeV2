# Telegram 交易通知

## 通知范围

- 买入信号和卖出信号写入数据库后发送通知。
- 买入交易和卖出交易成功落库后发送通知。
- 模拟盘和实盘都发送，并在消息中明确标记交易模式。
- 页面在模拟盘和实盘之间成功切换后发送通知，包含原模式、新模式、当前交易钱包和切换时间；模式未变化时不重复发送。
- 每次切换汇总上一段模式区间：成交买入、成交卖出、失败订单、已平仓数量及胜负、实现盈亏、当前未平仓数量和持续时间。
- 模式区间从上一次切换成功开始计算，开始时间使用 `system_runtime_settings.trade.mode.started_at` 持久化，服务重启不重置；功能首次上线时从服务启动时间开始统计。
- 切换到实盘前通过生产 Solana RPC 查询当前钱包余额；查询成功后才切换，并在 TG 通知中显示 SOL 余额。切回模拟盘不显示余额。
- 重复 Redis 信号、报价拒绝、执行失败的订单不发送“交易成功”通知。

## 配置

配置位于 `telegram` 节点，包括 `enabled`、`bot_token` 和 `chat_id`。生产环境的真实 Token 与私聊 ID 仅写服务器配置，不进入代码仓库。
