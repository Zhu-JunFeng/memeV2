# 候选池容量与项目元数据

## 规则

- 候选池最多保留 50 个项目。
- 每批来源项目先处理当前市值 50k–200k 的项目，再处理其他项目。
- 池满后不为了新项目淘汰已有项目；项目入池后只在实时市值低于 10k 时移除。
- 来源已经明确给出市值且低于 10k 的项目不入池，避免被移除后每分钟重复加入。
- 升级时若已有候选超过 50，执行一次容量收敛，优先保留当前市值 50k–200k 的项目。
- XXYY 与 GMGN 返回的 symbol 和来源市值在入池时写入候选状态，修复自动来源 CA 的 symbol 缺失。

## 字段来源

- XXYY：symbol 优先读取 `symbol`、其次 `name`；市值优先读取 `marketCapUSD`、其次 `marketCap`。
- GMGN：symbol 读取 `symbol`；市值读取 `usd_market_cap`。
- 若存量候选仍缺少 symbol，则通过 GMGN `GET /v1/token/info` 按 CA 补齐。
- 入池后继续使用 GMGN K 线折算的实时市值更新候选状态，来源市值只用于首次排序和初始化。
