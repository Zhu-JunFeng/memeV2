# 买入报价重试与候选状态同步

## 买入报价

- 买入信号第一次 Jupiter 报价相对信号市值偏差大于 `3%` 时，不立即拒绝。
- 系统继续连续重试 `3` 次，总计最多请求 `4` 次报价。
- 任意一次报价偏差回落到 `<=3%`，继续执行买入；四次均超过 `3%` 才拒绝。
- 本次不调整模拟盘执行阶段的第二次报价行为。

## 候选状态

- 候选项目发布买入信号后，卖出监控必须等待该买入信号实际变为 `executed`。
- 买入最终为 `rejected`、`failed` 或 `skipped` 时，候选项目自动恢复 `watching`，清除本次买入状态并继续寻找后续买点。
- 没有可卖持仓的卖出信号记为 `skipped`，不再错误标记为 `executed`。

## Positions symbol

- Positions 优先读取上游 `token`，缺失时读取 `symbol`，兼容项目候选数据结构。
