# 试压阳线量能门槛调整

## 背景

压力突破策略中，试压 K 线用于确认“多根阳线触及压力带但未突破”的结构。原规则要求试压阳线成交量达到最近 `volumeWindow` 根均量的至少 `1.35x` 与 `volumeMultiplier` 中较高者。

## 变更

- 试压阳线最低量能倍数从 `1.35x` 调整为 `1.6x`。
- 实际规则变为：`volume >= 最近 volumeWindow 根均量 * max(volumeMultiplier, 1.6)`。
- 当前默认 `volumeMultiplier=1.2`，因此生产默认试压阳线需要达到最近均量的 `1.6x`。

## 影响

- 弱量触压 K 线不再纳入试压组。
- 压力突破买点数量会减少，触发质量更偏向放量试压后的突破。
- 不改变压力位计算、突破阈值、买入金额、模拟盘/实盘模式和卖出规则。
