# 本地水平压力页加载优化

## 背景

本地前端 `/horizontal-pressure` 已改为直接通过 Vite 代理访问生产后端。页面原先默认 `回看小时=0`，表示不传 `startTime/endTime`，会请求全部 1m K 线。生产后端本机返回很快，但公网传输大 JSON 较慢，页面表现为长时间加载不出来。

## 变更

- `/horizontal-pressure` 默认回看小时改为 `24`，页面首次加载只请求最近 24 小时 K 线。
- 生产 nginx 开启 gzip，压缩 `application/json` 等响应，降低本地直连生产后端时的传输体积。

## 约束

- 不新增备用数据源。
- 不恢复 `8890` SSH tunnel。
- 不修改或恢复交易记录表；本变更只影响 K 线页面加载和 nginx 传输压缩。
