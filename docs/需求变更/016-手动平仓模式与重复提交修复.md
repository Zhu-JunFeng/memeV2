# 手动平仓模式与重复提交修复

## 问题

- Positions 的手动平仓原先使用系统当前全局交易模式，而不是目标持仓自己的交易模式。筛选或查看另一种模式的持仓时，可能走错模拟盘或实盘执行通道。
- 手动平仓没有占用卖出在途锁，重复点击或与自动卖出并发时可能重复提交。
- 前端按钮没有确认、单行 loading 和重复点击保护。

## 修复

- 手动平仓始终使用 `position.tradeMode` 创建卖出信号、订单和成交记录。
- 提交前校验持仓仍为 `open`，并对该 CA 获取卖出在途锁；正在卖出时返回 `409`，不重复调用执行器。
- 前端明确展示本次平仓是模拟盘还是实盘，确认后提交；提交期间禁用其他平仓按钮并显示 loading。
- 执行失败或信号保存失败时释放在途状态并恢复 open position，允许用户重试。
