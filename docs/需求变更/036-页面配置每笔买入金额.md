# 页面配置每笔买入金额

## 需求

- 每笔买入金额可以在交易看板页面修改。
- 模拟盘和实盘共用同一个金额。
- 默认金额为 `10 U`。

## 实现

- `GET /api/trade/runtime` 返回 `buyAmountUsd`。
- `PUT /api/trade/runtime` 支持部分更新 `buyAmountUsd`，数值必须大于 `0`。
- 金额保存到默认交易账户的 `trade_accounts.buy_amount_usd`，同时更新交易服务的运行时账户快照，无需重启即可从下一笔买入生效。
- 买入开始时固定读取一次账户快照，报价预检、订单意图和 Jupiter 执行使用同一个金额，避免保存配置与下单并发时一笔订单出现两种金额。
- 页面“每笔买入金额”提供数字输入和保存按钮，并明确显示模拟盘、实盘通用。
- 配置文件和数据库列默认值统一调整为 `10`；`EnsureAccount` 仅在首次创建账户时使用配置金额，不会在重启时覆盖页面保存值；已有订单和持仓不受修改影响。

## 验证

- 后端覆盖账户金额持久化、运行时同步和非法金额拒绝测试。
- 前端执行组件测试及生产构建。
- 部署后验证运行时接口和交易账户接口均返回 `10`。
