# 卖出检查频率与实际成交成本

## 卖出参数

- 默认固定止盈由 `8%` 调整为 `10%`。
- 动态止损由盈利 `5%` 启动并锁定 `3%`，调整为盈利 `7%` 启动并锁定 `4%`。
- 动态止损启动后，最高盈利每增加 `1%`，锁定收益率同步增加 `1%`。
- 买入后所有后续 1 分钟 K 线都持续检查；正式收盘且收盘市值低于压力带下沿时卖出。

## 检查频率

- 未持仓候选项目继续按普通候选轮询周期检查买点。
- 模拟盘和实盘持仓都进入独立的 `0.5s` 卖出检查循环，只处理状态为 `bought` 的项目。
- 同一根盘中 K 线允许重复检查止盈和动态止损，不再因为本分钟已经检查过一次而跳过后续价格变化。
- 每根 1 分钟 K 线正式收盘后，`0.5s` 循环会继续检查依赖收盘价的压力带下沿止损规则。

## 实际成交成本

- 买入信号执行成功后，根据外部信号 ID 查询对应的已开仓持仓。
- 使用 Jupiter 实际成交均价乘 token supply 得到实际买入市值。
- 候选状态和压力带买点同步更新为实际买入市值后，才开始执行止盈、动态止损和盈亏计算。
- 查询不到实际持仓或实际成交市值无效时，不使用信号市值替代，等待后续轮询重新同步。
