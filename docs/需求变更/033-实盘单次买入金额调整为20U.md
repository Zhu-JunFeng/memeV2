# 实盘单次买入金额调整为 20U

## 需求

生产实盘每笔买入金额由 `10u` 调整为 `20u`。

## 实现

- `trade.buy_amount_usd` 默认值和生产部署配置调整为 `20`。
- `trade_accounts.buy_amount_usd` 数据库列默认值调整为 `20`。
- 服务启动时通过现有 `EnsureAccount` 将生产默认账户的买入金额同步为 `20`。
- Jupiter 下单仍按下单时 SOL/USD 价格将 `20u` 换算成 SOL lamports，不改变 RTSE、滑点保护、报价预检或买卖策略。

## 验证

- 部署后 `/api/trade/accounts` 中默认账户的 `buyAmountUsd` 应为 `20`。
- 下一笔实盘买单的 `intentAmountUsd` 应为 `20`。
