# 生产后端交易数据查询接口

## 背景

本地前端原先通过 Vite 代理到 `localhost:8890`，再依赖本地 SSH tunnel 转发到生产后端。为了减少本地联调依赖，改成本地前端直接通过生产后端公开的 `/api` 查询生产数据，不再要求启动 `8890` tunnel。

## 变更

- 新增 `GET /api/trade/daily-stats`，由生产后端读取数据库并返回按北京时间自然日聚合的交易统计。
- 默认查询 `paper` 模式最近 `5` 天，支持 `tradeMode=paper|live|all` 与 `days=1..90`。
- 统计覆盖 Signals、Orders、Opened Positions、Closed Positions、胜负、胜率和已实现盈亏。
- 本地 Vite 开发代理从 `http://localhost:8890` 改为 `http://47.251.140.83`，浏览器继续访问本地 `/api`，由 Vite 直接转发到生产后端。

## 约束

- 前端不直接连接 PostgreSQL，也不暴露数据库账号。
- 接口不支持任意 SQL，只提供业务限定的只读统计查询。
- 不添加备用数据源或降级逻辑。
