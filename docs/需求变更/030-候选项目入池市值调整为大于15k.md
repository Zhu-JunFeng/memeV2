# 候选项目入池市值调整为大于 15k

## 变更内容

- XXYY 与 GMGN 自动项目源返回的项目，只有当前市值严格大于 `15_000` 时才允许首次进入候选池。
- 当前市值缺失、等于 `15_000` 或低于 `15_000` 的项目均不入池。
- 原有 `KOL >= 3`、CA 非空和同批去重规则继续生效。

## 与移除规则的关系

- 本次只调整自动项目首次入池条件。
- 项目入池后继续使用 GMGN K 线折算的实时市值更新状态。
- 已入池且未持仓的项目仍只在实时市值低于 `10_000` 时移除，不把移除阈值同步提高到 `15_000`。
- 手动添加 CA 的接口保持原行为，不依赖上游项目源市值字段。
