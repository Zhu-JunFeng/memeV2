# 压力带失效与手动平仓修复

## 压力带失效

- 压力带以形成该压力带的最后一个有效试压触点作为形成时间。
- 从形成时间之后开始累计 1m K 线；当累计出现 3 根阳线，并且每根收盘市值都严格高于压力带上沿时，该压力带失效。
- 三根不要求连续；阴线或收盘未超过上沿的 K 线不计数。
- 失效压力带不得继续用于生成买入信号，必须等待后续新的有效试压组合形成新压力带。
- 实时监控和历史回测使用同一失效判断。

## 手动平仓

- 手动平仓信号写入非空 `raw_payload_json`，避免数据库 `NOT NULL` 约束导致接口在创建信号时返回 500。
- payload 记录来源、Position ID 和 Position 自身交易模式。
- `triggerPrice` 使用当前 token 价格，`triggerMarketCap` 使用当前价格乘以 token supply，不再把价格误写为市值。
