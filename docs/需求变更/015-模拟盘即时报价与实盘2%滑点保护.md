# 模拟盘即时报价与实盘 2% 滑点保护

## 需求

- 模拟盘按照 Jupiter 即时报价成交，不额外扣除滑点。
- 实盘调用 Jupiter `/order` 时使用固定 `slippageBps=200`，将 2% 滑点保护写入交易，签名后再调用 `/execute`。

## 实现语义

- 模拟盘调用 Jupiter `quote`，直接使用返回的 `inAmount` 和 `outAmount` 计算模拟成交数量与成交均价，不再对结果额外扣减滑点。
- 实盘的 2% 是固定滑点上限。Jupiter 在 `/order` 收到数值型 `slippageBps=200` 后会覆盖自动 RTSE；`/execute` 只提交和确认已包含该滑点约束的签名交易。
- 如果链上执行结果无法满足交易中写入的最低接收数量，交易失败，不按超过 2% 的更差价格成交。

## 配置

```yaml
trade:
  slippage_bps: 200
```

`200 bps = 2%`。生产环境应保持该配置值为 `200`。
