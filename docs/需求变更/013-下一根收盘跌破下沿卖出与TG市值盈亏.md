# 下一根收盘跌破下沿卖出与 TG 市值盈亏

## 卖出规则

- 买入后的后续 K 线不因盘中最低市值跌破压力带卖出。
- 买入后所有后续 1 分钟 K 线都持续检查；任意一根正式收盘，并且收盘市值严格低于压力带下沿时，按该根实际收盘市值触发卖出信号。
- 本次变更当时硬止损、动态止损和止盈规则保持不变；固定百分比硬止损已在后续需求 `017-移除固定硬止损` 中删除。

## Telegram 通知

- 买入信号和卖出信号展示信号触发市值。
- 买入交易和卖出交易展示 Jupiter 实际成交均价乘以 Token Supply 得到的实际成交市值，不复用信号触发市值。
- 市值统一除以 `1000`，保留两位小数并使用 `k` 单位。
- 卖出信号展示基于买入/卖出触发市值计算的预估收益率。
- 卖出交易展示基于实际买入成本和实际卖出回款计算的已实现收益率，标记为 `盈亏（U）`。
- 收益率保留两位小数，并明确显示正负号。
