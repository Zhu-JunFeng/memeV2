# 交易汇总总盈亏口径修复

## 问题

`/api/trade/summary` 原先用 `realized_pnl + unrealized_pnl` 直接汇总所有持仓。当历史 closed 持仓因为事故恢复或人工修正残留了 `unrealized_pnl` 时，页面总盈亏会把这部分历史浮盈亏重复计入，导致 totalPnl 与已实现盈亏、当前未实现盈亏口径不一致。

## 修复

- `totalPnl` 改为：全部持仓 `realized_pnl` + 仅 open 持仓 `unrealized_pnl`。
- `unrealizedPnl` 原口径保持不变：只统计 open 持仓。
- `paper`、`live`、`all` 三组汇总使用同一口径。

## 验证

- closed 持仓即使残留非零 `unrealized_pnl`，也不会进入 `totalPnl`。
- open 持仓的浮动盈亏仍会计入 `totalPnl` 和 `unrealizedPnl`。
